# Den

Den helps people plan gatherings and discover event vendors in Toronto and the Greater Toronto Area.

Customers can browse approved vendors, describe their event, refine results by service, location and price, and save vendors to their event plan. Vendor profiles bring business details, services, pricing and portfolio images together.

Vendors use a guided setup to add their business, services, service areas, pricing and photos before submitting their profile for review. Den administrators review submissions before they appear in customer discovery.

The project includes a Django website and shared REST API, alongside an Expo mobile client. Discovery and event matching use the same backend across web and mobile. Ratings use verified Den reviews.

Den is under active development. Test environments may contain clearly labelled fictional demo vendors. Published prices are indicative, and vendor discovery does not confirm availability or a booking.
